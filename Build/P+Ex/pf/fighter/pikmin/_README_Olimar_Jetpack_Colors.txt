========================================
Guide for Olimar Jetpack Colors
========================================
Olimar uses a new per-costume model color system for his jetpack model.

These colors are stored in FitPikmin.pac, inside ARC ef_pikmin > Model Data [7] > AnmClr > EffPikminJetsCLR > JetPack > ConstantColorRegister2

From here, each frame controls the costume ID corresponding to that frame, defaulting to red if not changed.

For modifying hidden costumes:
61 equals AltR
62 equals AltZ
