========================================
Guide for Adding Wario Costumes
========================================
Wario costumes work differently than most characters do due to having slot-dependent bones. 

Slots 0-5: Use the Biker jacket boneset
Slots 6-11: Use the Classic Wario boneset
Slots 12+: Use the Biker boneset again

Using the wrong boneset will crash the game! If you wish to add further costumes to Wario, make sure to use correct bone set for the slots.

For tag-based costumes, putting a Classic Wario costume over a Biker slot can have unintended character shadow effects, and can crash the game. Using a Biker costume over a Classic slot can also have unintended effects.

Additionally, Wario cannot use costume IDs 15, 31, or 47. These slots will crash when used with Wario Man. Higher numbered slots, 48-60, can be used instead.
