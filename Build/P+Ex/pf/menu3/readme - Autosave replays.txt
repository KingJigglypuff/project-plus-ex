The code menu (accessible with L + R + d-pad down) includes functionality to
automatically save match replays to the SD card!

This can be toggled on/off in-game, but can also be set to ON by default
by doing the following:

1. Rename data.cmnu to something else
2. Rename data_AUTOSAVE_ON.cmnu to data.cmnu

To revert this, simply swap the filenames back.
